One Line, One Laugh — a deterministic writer for a single funny line.

## Run it

```sh
node main.ts
```

`main.ts` writes exactly one UTF-8 line to `/output/entry.txt`. It needs no
dependencies, network access or environment configuration, and it checks the
1–200 character gate before writing.
